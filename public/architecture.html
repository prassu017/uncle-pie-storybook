Architecture

How Uncle Pie works

gpt-3.5-turbo writes and judges every word of the story. Plain code orchestrates and keeps score. Other models only draw, see, speak and listen.

3. The judges

gpt-3.5-turbo alone is too lenient, so Vishnu combines code checks, two quote-verified reads (fidelity and story logic) and a rubric.

4. A picture worker

Five run at once, separately from narration, each sharing one cast sheet.

stateDiagram-v2
    [*] --> Directing: finished page text + required moment
    Directing --> Painting: Uncle Pie's shot spec + cast sheet + family photos
    Painting --> Judging
    Judging --> Done: shows the moment
    Judging --> Redrawing: wrong moment, wrong look, text, or unsafe
    Redrawing --> Rejudging: art judge's rewritten shot spec
    Rejudging --> Done: pass or flag, never loops forever
    Done --> [*]
    note right of Painting: rate limited (5 images a minute)?
wait as long as OpenAI asks, retry

Narration and picture requests run in parallel from the browser, keeping each serverless call short. The key lives only in an environment variable; an optional passcode can lock a deployment.

6. Agents

Each agent is named after a pioneer of its job.

7. Key decisions

  • Code assigns the family's ideas to pages. The model claimed "page 2 covers the rescue" when no page did.
  • One page per writing call, each seeing the story so far. Writing all five at once swapped who rescued whom.
  • The judge must quote evidence, and code checks the quote. gpt-3.5 alone passed a story missing half the plot.
  • Image prompts are structured shot specs, action first. "Fox helps Bear" was once drawn as Fox running away.
  • A cast sheet is painted first and shared with every page. Parallel pages otherwise drifted (a robot became a hedgehog).
  • Each page gets one new event, checked in code. Testing showed a lesson being taught twice; whole-story and page-by-page writing were compared and neither won clearly.

The book opens as soon as the text passes review; narration and pictures follow in parallel.
